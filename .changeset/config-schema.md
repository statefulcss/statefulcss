Define every setting in one schema: `themeAttribute`, `themeFiles`, `baseTheme`, `blockingStates`, `interactionStates`, `stateAttributes`, `layers`, `strict` and `ignoreLayers`, each with its type, default and a one-line description. `StatefulCSSConfig`, `Settings`, `defaults` and `schema.json` come from it, and `schema.json` gives editors each setting's description, default and an example.
