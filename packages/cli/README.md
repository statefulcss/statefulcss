# Stateful CSS CLI

Command line tools for Stateful CSS.

## Installation

Run without installing globally:

```bash
pnpm dlx statefulcss --help
```

Or install globally:

```bash
npm install -g statefulcss
statefulcss --help
```

## Usage

```bash
statefulcss --help
statefulcss --version
```
