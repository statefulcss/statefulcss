# Stateful CSS Core

Reads a stylesheet the way Stateful CSS sees it, and describes it: its components, their elements, the kind of every block, and the role of every variable. The Stylelint plugin and the other Stateful CSS tools read the same model.

**In development, not ready for use.** Nothing in it works yet, and its API will change before the first release.

Its API is for tools, not for projects: you don't install it directly, it comes with the Stylelint plugin. Before 1.0, the model can change in any minor version.
