# `@repo/eslint-config`

Collection of internal eslint configurations.

- `@repo/eslint-config/base`: JavaScript, TypeScript, Turborepo and Prettier rules for every workspace package.
- `@repo/eslint-config/node`: `base` plus Node.js globals, for packages that run on Node.js.
